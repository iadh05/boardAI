# Learning log

Write here as you go. Short and honest beats polished. This is where the "Before you start" and "Self-check" answers from each spec go, and it's gold for interview prep later.

## Entry template

```markdown
### YYYY-MM-DD — <ticket or topic>
- **Did:** what I built / read
- **Learned:** the one thing I'd explain to someone else
- **Stuck on:** what took longest and why
- **Next:** what I'll do next session
```

## Milestone retro template

```markdown
## Retro — M<n>
- **Demo passed on:** YYYY-MM-DD
- **Estimate vs actual:** planned X days, took Y
- **What went well:**
- **What hurt:**
- **What I'd do differently:**
- **Self-check answers:** (from the spec)
```
